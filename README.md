## Descripción
Sistema de carrito de compras en Python que permite consultar un catálogo de productos, agregar y eliminar productos del carrito, calcular subtotales, aplicar descuentos y generar un ticket de venta.

## Instrucciones de ejecución
1. Clonar este repositorio:
   ```
   git clone [LINK DEL REPOSITORIO]
   ```
2. Entrar a la carpeta del proyecto:
   ```
   cd [nombre-carpeta]
   ```
3. Ejecutar el programa principal:
   ```
   python main.py
   ```
4. Seguir las opciones del menú que aparece en la terminal.

## Estructura del proyecto
- `main.py` – Menú principal e integración de módulos
- `catalogo.py` – Carga y muestra del catálogo de productos
- `carrito.py` – Lógica para agregar, eliminar y calcular el carrito
- `descuentos.py` – Reglas y aplicación de descuentos
- `ticket.py` – Generación del ticket de venta
